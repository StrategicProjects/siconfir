# siconfir: Access Brazilian Fiscal Data from SICONFI API

Provides functions to access fiscal data from the Brazilian National
Treasury's SICONFI API
<https://apidatalake.tesouro.gov.br/docs/siconfi/>. Includes budget
execution reports (RREO), fiscal management reports (RGF), annual
accounts declarations (DCA), accounting balances matrices (MSC), and
entity information for all Brazilian states and municipalities. Features
automatic pagination, in-memory caching, and tidy output.
